# 🛡️ MBR – My Best Raksha

## Healthcare Assistance & Emergency Support System

MBR (My Best Raksha) is a Java Full Stack healthcare assistance web application designed to help users find the appropriate medical specialist based on their reported health problem and locate nearby healthcare facilities.

## 🚀 Features

- 🔎 Find the appropriate doctor specialty based on the user's problem
- 🎤 Voice-based problem input
- 🌐 Multilingual voice input
- 📍 GPS-based location detection
- 🏥 Find nearby doctors and healthcare facilities
- 🗺️ View nearby locations on a map
- 🚨 Emergency assistance with quick access to emergency services
- 💻 Responsive web interface

## 🛠️ Technologies Used

- Java
- Spring Boot
- Maven
- MySQL
- HTML5
- CSS3
- JavaScript
- REST APIs
- Web Speech API
- Browser Geolocation API
- Leaflet Maps

## 👨‍💻 Project Purpose

The main goal of MBR is to make healthcare assistance easier by helping users identify the suitable type of doctor and find nearby healthcare facilities based on their location.

> **Note:** Doctor-specialty recommendations are preliminary guidance and are not a medical diagnosis.

## ▶️ How to Run

1. Clone the repository.
2. Open the project in VS Code or IntelliJ IDEA.
3. Make sure Java and MySQL are installed.
4. Configure the MySQL database in `application.properties`.
5. Run the Spring Boot application using:

```bash
./mvnw spring-boot:run
